Features

One box for everything you reach for.

No mouse trips to the Start menu, no digging through Explorer. Just type.

Instant app search

Every app from the Start menu, desktop and Microsoft Store, with duplicate shortcuts merged into one clean result.

Files & folders

Documents, photos, slides and more, found by name anywhere in your Desktop, Downloads, Documents and Pictures, even deep in subfolders. New files show up in seconds. Shift Enter reveals one in Explorer.

Learns what you use

Results rank by how often you open them, and when. Your morning apps rise in the morning. The best match is always the Top Hit.

Maths & currency

Type 12*(3+4) or 100 usd to eur and get the answer as you type. Enter copies it.

Web shortcuts

Type a URL to open it, then Ctrl Enter to save it under a short name like gh. Search the web with > g.

System actions

Lock, sleep, restart or shut down with a confirmation first, or type system for live CPU, memory and disk usage.

Privacy

Your files stay on your PC.

Spotlight-Win searches your computer, not the internet. There's nothing to sign up for and nothing running in the cloud.

  • Local index. File names, launch history and shortcuts are stored only in your Windows profile.
  • No telemetry or ads. No analytics and no tracking, and nothing about your searches leaves your PC.
  • No account. Install it and press Ctrl Space.
  • No web results mixed in. Results come from your own apps and files.

The one exception: when you type a currency conversion, Spotlight-Win fetches exchange rates from frankfurter.app (European Central Bank data), cached for an hour. Your search text is never sent.

Under the hood

Native, small and quick.

A Rust core with a lightweight system webview, not a bundled browser. It idles quietly in your tray until you need it.

Rust

Indexing, ranking, launching and Windows integration, all in native code.

Tauri 2

A tiny app shell using the WebView2 already on Windows, so no Chromium is bundled.

Tantivy

A Rust search library behind the name index, with prefix and multi-word matching.

Windows APIs

Native app icons, Shell launching, process detection and system stats.
